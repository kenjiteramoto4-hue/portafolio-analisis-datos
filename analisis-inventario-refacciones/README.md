# Costos e inventario de refacciones

## Descripción

Análisis de costos e inventario de refacciones para identificar las piezas que concentran el mayor gasto y los principales problemas de disponibilidad.

El proyecto analiza 2,124 movimientos de inventario utilizando Python, pandas y SQL.

## Objetivo

Identificar las refacciones con mayor impacto económico y detectar patrones de consumo, concentración del gasto y quiebres de stock que puedan afectar la operación.

## Hallazgos principales

El **85% del gasto** está concentrado en las **5 refacciones principales**.

Las piezas críticas presentan aproximadamente el **doble de quiebres de stock** que las demás refacciones.

Estos resultados permiten identificar las piezas que requieren mayor atención para mejorar la disponibilidad y la gestión del inventario.

## Herramientas

- Python

- SQL

- Visualización de datos

- `datos/` — Dataset utilizado para el análisis.

- `sql/` — Consultas SQL utilizadas.
- `generar_datos.py` — Script para generar los datos sintéticos.

## Resultado

El análisis permite identificar las refacciones que concentran el mayor impacto económico y los principales riesgos de disponibilidad, proporcionando información útil para priorizar decisiones de inventario.

Los datasets utilizados son sintéticos y fueron generados para el análisis. No contienen información de ninguna empresa real.
